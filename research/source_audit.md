# 公开资料、代码与研究空缺审计

审计日期：2026-10-15。此文件记录可核对的实现差异，不推断原论文作者的主观意图，也不把代码差异自动等同于论文结论失效。

## 数据与上游代码

- 原论文：[Demirel 等，TVCG 2025](https://doi.org/10.1109/TVCG.2025.3549132)，公开 EEG 与头动晕动症研究；论文报告 16 名参与者。
- [2025 README 的固定版本](https://github.com/eth-siplab/EEG_Cybersickness_Estimation_VR-Beyond_Subjectivity/blob/cbe89fa6de141a2d07ea247e55a45a0f4160da4a/README.md) 给出 [公开数据目录](https://drive.google.com/drive/folders/1ijWfyNYktqKV0ACpgCNOLuhJf8YsWYfB)。研究数据仅本地使用，不随代码重新分发；数据的再分发许可不能从代码 README 的 MIT 声明推定。
- 固定下载的复现代码版本为 `bf8627d130686609ba67594c40c5bf6f20e74d17`，该版本于 2026-06-20 增加重建的预处理前端。不能把它全部称为论文发表时的原始发布代码。
- 上游 `preprocess.py` 使用双向滤波；`loader.py` 中谱差分对第 i 行使用 `[i:i+3]` 平均，并对 joy 产生差分、ERP 与累计最大值标签。它与本项目原始摇杆未来峰值任务不是同一任务。
- 原 loader 的 `train_mean` 元数据涉及整段标签均值，需核对实际模型/指标使用路径；仅见该字段不能断言模型用了测试标签。
- 当前不把上游 README 的复现数值当作本项目实验结果。精确复现和按新因果目标重训是两种不同实验，必须分别命名。

## 时间与数据质量

首个导出的 `0001_FN_EEG` 有重复接收毫秒，HardwareSeconds 仅一个值；头动和评分在记录尾部另有大间断。新流程使用真实接收时钟分窗，避免按行号假造三路完全同步。所有记录均需进行同类审计，不预先硬编码“只有 13 人有效”。

## 新颖性核验

| 已有工作 | 对选题的约束 |
|---|---|
| [Islam 等，ISMAR 2022](https://doi.org/10.1109/ISMAR55827.2022.00026) | 已研究多模态晕动症发作预测；不能声称首次提前预警。 |
| [Choi 等，UbiComp Companion 2024](https://doi.org/10.1145/3675094.3677578) | 已用多模态时序模型做提前预测；仅使用时序模型不是空缺。 |
| [Demirel 等，TVCG 2025](https://doi.org/10.1109/TVCG.2025.3549132) | 直接相关的 EEG/头动连续估计和公开数据方法。 |
| [Ridwan 等，TVCG 2026](https://doi.org/10.1109/TVCG.2026.3680682) | 已联合建模症状严重度、模糊干预有效性与强度；检测到干预的连接也不是空白。 |
| [ISMAR 2026 官方论文列表](https://www.ieeeismar.net/2026/papers/) | 已有少样本个性化 30/60 秒预测工作，投稿前还需核对全文、数据及对照实现。 |
| [Romano 等，NeurIPS 2019 CQR](https://papers.neurips.cc/paper_files/paper/2019/hash/5103c3584b063c431bd1268e9b5e76fb-Abstract.html) | 分位数保形校准是既有方法，应用它不能宣称新理论。 |
| [Jeong、Han，PRECYSE，IMWUT 2024](https://doi.org/10.1145/3659594) | 已有多模态时空 Transformer 与 MSCVR 公开样本，不能将 Transformer 或多模态融合作为独立创新。 |

当前候选贡献是：接收时间与因果处理可审计的预警评测，未见用户上的误警/覆盖/提前量权衡，以及小规模闭环可行性。这个贡献是否够强必须由完整对照、结果和新文献审查支持，尚不能保证 VRST 可录用。

## 独立数据的可用性核验

2026-10-15 检查了 [PRECYSE 作者仓库](https://github.com/dayoung-jeong/PRECYSE)。README 明示维护中，发布内容为归一化传感器、频谱图和等级标签。抽查 `Data/00/label.csv` 为无表头的三列整数等级，`sensor/` 则按样本编号分文件。该检查尚未证明它提供与本项目相同的接收时间、连续评分及未来 6 秒目标，不能直接拼接成第二套等价验证数据。需先核对完整标签日程、样本顺序、时间戳和归一化所使用的范围，再制定独立协议。不能仅因存在公开 CSV 就声称完成跨数据集验证。

[ISMAR 2026 官方程序](https://www.ieeeismar.net/2026/papers/) 已核验个性化预测论文的完整作者及题名；本文以程序条目引用，不编造未核实的 DOI/页码。程序还列出自适应减轻研究，因此论文的创新论证必须进一步缩小到可审计的动作提前量和预警代价，并通过证据支持。
