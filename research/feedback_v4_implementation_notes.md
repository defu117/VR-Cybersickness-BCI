# v4 实现与协议措辞说明

日期：2026-10-19。本说明补充已冻结协议的实现细节，不修改已运行模型、输入、阈值规则或主比较。原冻结方案与代码校验值保留。

## 1. 编号加权与类别平衡的顺序

拟合表包含各拟合编号的 9 种模拟反馈条件。设拟合行数为 N、拟合编号数为 G，编号 i 有 n_i 行，基础权重为 `w = N / (G * n_i)`。

- 峰值回归直接使用基础权重，每个拟合编号的权重总和相同。主要 MAE 比较对应这一实现。
- 事件分类先使用同样的基础权重，再按拟合组加权后的类别总量平衡正、负类：类别 c 的总基础权重为 W_c，则最终权重为 `w_class = w * N / (2 * W_c)`。
- 经过类别平衡后，分类器各编号的最终权重总和可能不同。因此协议中“每编号总权重相同”严格对应基础权重和回归器，不应扩写为分类器最终权重仍逐编号相等。分类/动作结果属于这一顺序重加权实现，未另选权重版本。
- 校准约束和最终汇总仍按编号宏平均，未用训练权重重加权测试结果。

## 2. 当前状态与未来事件

真实当前评分只用于离线标签。最近报告保持基线假定未来保持最近已到达值，事件分数固定为零，不读取真实当前值来构造“未来预测减当前真实评分”的报警分数。两种 HGB 方法分别拟合峰值回归和事件分类，不能由回归误差改善直接推导事件/动作改善。

## 3. 条件、场景和身份

本轮改变的是同一记录的模拟反馈可用性；9 个条件不是 9 组新参与者。训练、校准与测试按作者编号隔离，没有整体留出场景，也没有对测试编号微调。编号与真实身份映射仍有局限，尤其第二源 PA112/PA114 的属性重合需进一步确认。

## 4. 记录与实际报告

时间、缺失和数值分辨率审计描述公开导出流。第一源的连续值变化不能直接恢复论文描述的报告档位事件；第二源的固定保存间隔也不是实际按需报告频率。模拟请求、固定传输延迟和旧评分年龄均不等同于测得的人的反应时间或负担。

## 5. 固定输入回放与闭环效果

模拟减速不会重新生成原始运动输入或原始症状轨迹。本轮只评价既定预测流驱动控制器时的动作机会，不包含动作改变后输入分布的反馈，也不能证明真实闭环策略的稳定性或减缓效果。倍率指控制器输出命令，不是测得的身体速度或症状反应。
